All Search Interest and query data come from Google Trends.

| Folder | Contents |
|---|---|
| [`search_interest/`](search_interest/) | prefecture-level Search Interest on the topic of "nuclear power plant", 2004–2024 |
| [`queries/`](queries/) | the top related queries for four Japanese search terms in March 2011, and each term's share of searches by prefecture |
| [`reference/`](reference/) | yearly reactor status and each prefecture's distance from Fukushima |

[`prefectures.csv`](prefectures.csv) is generated by [`notebooks/1_data_preparation.ipynb`](../notebooks/1_data_preparation.ipynb). Each row gives the following information for one prefecture, as used in the paper's analysis:
- Search Interest in each of the five periods;
- host status in each period, which is 1 if at least one reactor in the prefecture was operable in at least one year of the period;
- border status in 2004–2010, which is 1 if the prefecture shares a land border with a host prefecture (host status = 1);
- distance from Fukushima (km).
