This folder contains Search Interest data from Google Trends on the topic 原子力発電所 ("nuclear power plant").
The Search Interest in each file is normalized separately, so values cannot be compared across files.

| File | Contents |
|---|---|
| `by_prefecture_<period>.csv` | one file per period (2004–2010, 2011, 2012–2014, 2015–2019, 2020–2024); columns `prefecture` and `search_interest` (the top prefecture in the period = 100) |
| `weekly_2011.csv` | weekly Search Interest from the week starting 26 December 2010 to the week starting 25 December 2011; one column per prefecture, each normalized so that the prefecture's maximum in this period is 100 |

"<1" marks a value below 1, which the paper's analysis counted as 1.
